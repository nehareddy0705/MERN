# Week 3 - Backend Development with Database

This directory contains backend assignments and projects for Week 3. The primary focus is on building robust APIs, integrating databases, and implementing standard security practices for web applications.

## Overview of Concepts
- **Express.js API:** Creating a RESTful backend server using the Express.js framework to handle various HTTP requests.
- **Database Integration:** Connecting to a MongoDB database using the Object Data Modeling (ODM) library, Mongoose.
- **Authentication & Security:** Implementing secure user authentication flows. This includes using `bcryptjs` for hashing user passwords before storage and `jsonwebtoken` (JWT) for securing protected routes.
- **Project Structure:** Organizing server code into a scalable modular structure consisting of routing (APIs), data models, custom middleware, and authentication logic.

## Learning Objectives
1. Understand how to design and implement RESTful API endpoints.
2. Learn how to connect a Node.js server to a NoSQL database (MongoDB).
3. Gain practical experience with user registration and login flows.
4. Implement token-based authentication to secure sensitive endpoints
